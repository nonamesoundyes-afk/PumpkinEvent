# PumpkinEvent — ивент «Великая Тыква»

Paper 1.21.11 · Java 21 · все тексты на русском (MiniMessage, настраиваются в `config.yml`).

## Сборка
```
gradle build
```
(или откройте папку в IntelliJ IDEA → Gradle → build). Готовый файл: `build/libs/PumpkinEvent-1.0.0.jar` — положите в `plugins/`.

## Команды (алиас: /тыква)
| Команда | Описание | Право |
|---|---|---|
| `/тыква start [x z]` | запустить ивент (случайное место или заданные координаты) | pumpkinevent.admin |
| `/тыква stop` | остановить ивент | pumpkinevent.admin |
| `/тыква reload` | перезагрузить config.yml | pumpkinevent.admin |
| `/тыква status` | состояние ивента | все |
| `/тыква где` (`where`) | координаты, стрелка и расстояние до тыквы | pumpkinevent.where |

## Как проходит ивент (по умолчанию 15 минут)
1. **0:00** — на случайных координатах вырастает огромная тыква, красивое сообщение в чат, титр, звук, боссбар «тыквы появятся через ...».
2. **3:00** — тыквы «открываются»: вокруг Великой Тыквы (9–20 блоков) появляются тыквы. Только их можно ломать, за каждую — ресурсы.
3. **Каждые 3 минуты** — предупреждение за 5 сек., затем все игроки подсвечены (Glowing) и ослеплены (Darkness).
4. **15:00** — подведение итогов (топ-3), блоки возвращаются на место.

Если сервер выключится во время ивента, блоки восстановятся при следующем запуске (`plugins/PumpkinEvent/backup.yml`).
